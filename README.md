# Finance Data Analysis Dashboard (Power BI)

## Overview
This project is an interactive Power BI dashboard created to analyze financial data and track key performance indicators.

## Description
Developed a finance dashboard using Power BI to visualize revenue, expenses, and profit trends, enabling data-driven decision-making.

## Tools Used
- Power BI
- Excel

## Key Features
- KPI tracking (Revenue, Profit, Expenses)
- Interactive filters and slicers
- Trend analysis using charts

## Insights
- Identified revenue growth patterns
- Analyzed profit margins
- Tracked financial performance over time
